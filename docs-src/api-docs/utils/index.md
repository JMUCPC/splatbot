# utils

Python helpers bundled with the Splatbot starter code.

| Module | What it is for |
| ------ | ---------------- |
| [utils.actions](actions.md) | Build the `Action` objects your `decide` method returns (`Actions.move()`, `splat()`, and the rest). |
| [utils.hex_grid](hex_grid.md) | Axial hex coordinates, directions, vectors, and `HexUtils(game_state)` helpers. |
| [utils.splatbot_data_types](splatbot_data_types.md) | Optional `BotInfo` / `GameState` typing templates for editors and static checks. |

The full API reference index is at [Python API reference](../index.md).
